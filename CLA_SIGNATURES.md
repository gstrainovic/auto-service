# CLA-Signaturen

Mit dem Eintrag in diese Datei akzeptierst du das [Contributor License Agreement](./CLA.md) in der dort genannten Version.

Format, eine Zeile pro Person, bitte alphabetisch einsortieren:

```
| GitHub-Benutzername | Name | Datum (JJJJ-MM-TT) | Im Namen von (optional) |
```

Der Automatik-Check vergleicht ausschliesslich den GitHub-Benutzernamen in der ersten Spalte, Gross-/Kleinschreibung spielt keine Rolle.
